# Changelog

Neon Hub: Full Borg is released with Neon Hub, at the same version.

## 1.17.0

- **First release.** The 2070 Item Compendium's Full Body Conversions:
  - **Full Borg: Bodies (2070s)**: all 25 bodies as actors, with the free chassis (option slots doubled), eyes, base chrome and chrome installed where they go;
  - **Full Borg: Packages & Parts (2070s)**: a package item for each body, the chassis parts, the Biosystem and brain food.
- **Go Metal (GM).** Install a body on a character or mook from the sheet's header or by dropping a package on it. Go Metal:
  - uninstalls the old chrome and adds a Biosystem;
  - doubles the Internal and External Body slots;
  - rolls the package's Humanity Loss once, or takes the average.

  The window can also **switch bodies** or **leave the body**.
