# Changelog

Neon Hub: Full Borg is released with Neon Hub, at the same version.

## 1.26.2

- The bodies' chrome takes Operating Systems and Enhancements ("installed items" switched on, as in the Item Compendium since Neon Hub 1.25.0), and their Operating Systems carry the "counts as Borgware" flag.

## 1.26.1

- Released with Neon Hub 1.26.1. No changes to Full Borg.

## 1.26.0

- Released with Neon Hub 1.26.0. No changes to Full Borg.

## 1.20.0

- Released with Neon Hub 1.20.0. No changes to Full Borg.

## 1.17.1

- **The Skydrivers and the CyberConductor now follow the Item Compendium.** The book now prints both, and Neon Hub uses its rows instead of its own entries:
  - the **Rocklin Augmentics Skydrivers** cost 1,000eb, like the Wyzard Romanova Cyberlegs;
  - the **Integrated Zetatech CyberConductor**'s program swap is once per Round, since a Program activates only once per Round.

  The Phoenix Security Unit and the Sage bodies carry the new text too.

## 1.17.0

- **First release.** The 2070 Item Compendium's Full Body Conversions:
  - **Full Borg: Bodies (2070s)**: all 25 bodies as actors, with the free chassis (option slots doubled), eyes, base chrome and chrome installed where they go;
  - **Full Borg: Packages & Parts (2070s)**: a package item for each body, the chassis parts, the Biosystem and brain food.
- **Go Metal (GM).** Install a body on a character or mook from the sheet's header or by dropping a package on it. Go Metal:
  - uninstalls the old chrome and adds a Biosystem;
  - doubles the Internal and External Body slots;
  - rolls the package's Humanity Loss once, or takes the average.

  The window can also **switch bodies** or **leave the body**.
